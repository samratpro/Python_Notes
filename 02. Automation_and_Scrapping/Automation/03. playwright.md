*Use when: you need to find an element on the page. This is the step you will use most.*

```
Freeze screen & inspect disappearing elements ( https://www.youtube.com/watch?v=Qzmb9bdNzZ4 )
```
- Method 1: look up style section > right side straight of the filter box (:hov) > click (:hov) > checked ✅ Emulate a focused Page
### 4.1 Basic selecting

```py
page.locator('any selecting path').first   # First element
page.locator('any selecting path')         # All elements
page.query_selector(' css element ')       # htmltag.classname, .classname #idname  #p[data-testid='editorParagraphText']
page.locator(//button[.='Post'])           # if text exists in a child-level element of the selected element
```

> **Note:** selectors passed to `page.locator()` are strings, so they need quotes, for example `page.locator("//button[.='Post']")` or `page.locator(".class_name")`.

> **Tip:** If `"text='Post'"` does not select the element, use `//button[.='Post']` or `//button[normalize-space()='Post']`. Full examples are in 4.2, Find by text.

### 4.2 Finding elements

#### Find by text

```py
# Find By Text
page.click("//button[.='Post']")  # Post is text of button
page.locator("//input[normalize-space()='Post']").fill('my text')
elements = page.query_selector_all("text='Element Text Name'")
page.locator("//button[normalize-space()='Post']")     # if text exists in a child-level element of the selected element
```

> **Note:** `"text='Post'"` may not match when the text sits in a child element or has extra spaces around it. Use an XPath selector instead:

```py
# Use XPath when text='Post' does not work
page.locator("//button[.='Post']").click()                       # matches the button's full text, even inside child elements
page.locator("//button[normalize-space()='Post']").click()       # same, and also ignores extra spaces and line breaks
page.get_by_role("button", name="Post").click()                  # another option, by accessible name
```

#### Find by class or id

```py
# find by class or id
page.locator(.class_name)     # single targeted class name
page.locator(#id_name)        # class name
page.locator(.class1.class2)  # multiple target class names from many classes
```

#### Find by XPath: get content, links and HTML

```py
# (//element[@identy='name'])[index]
element = page.locator("//any-path").first.text_content()            # Find first element's content -- suitable for mouse and keyword event
element = page.query_selector('//any-xpath').text_content()          # Find first path only -- suitable for get content
elements = page.query_selector_all('//any-xpath')                    # Find all path -- suitable for get All Content
elements = page.query_selector_all("text='Element Text Name'")        # Find all by text
for e in elements:
    print(e.text_content())

elements = page.query_selector_all('//any-xpath')[1]                            # Find second element
link = page.query_selector('//any-xpath').get_property('href')                  # Get link - img src, title, class, id
link = page.locator("//any-path").get_attribute('href')
inner_html = page.query_selector('//any-xpath').inner_html()                    # Get inner HTML of any selected part
inner_text = page.query_selector('//any-xpath').inner_text()                    # Get inner TEXT of any selected part
```

#### Find by role, text, label, placeholder and more

```py
page.get_by_role('type', name="value") # locate by explicit and implicit accessibility attributes.
page.get_by_text()                     # locate by text content.
page.get_by_label()                    # locate a form control by associated label's text.
page.get_by_placeholder()              # locate an input by placeholder.
page.get_by_alt_text()                 # locate an element, usually image, by its text alternative.
page.get_by_title()                    # locate an element by its title attribute.
page.get_by_test_id()                  # locate an element based on its data-testid attribute (other attributes can be configured).
page.get_attribute()                   # argument can be 'href', 'src' etc
# https://playwright.dev/docs/locators 
```

> **Note:** The selectors in the text, class and id examples above need quotes, for example `page.locator(".class_name")`.

### 4.3 Handle multiple elements

```py
get_all_links = page.locator("multiple_elements_selector")

# Use element_handles() to get all matching elements
all_link_elements = get_all_links.element_handles()

# Iterate over each element and print its href or text
for link in all_link_elements:
    href = link.get_attribute('href')  # Get the href attribute
    print(href)  # Print the link href

elements = page.query_selector_all('//any-xpath')
for e in elements:
    print(e.text())

i = 1
while True:
    asn_btn = page.locator(f"((//div[@class='name'])[{str(i)}]//button)[1]")
    if asn_btn.count() > 0:
        asn_btn.click()
    else:
        break
```

> **Note:** `e.text()` is not a Playwright method. Use `e.text_content()` or `e.inner_text()`.

## Step 5. Check element behaviour

*Use when: you need to check whether an element is visible, enabled or editable before acting on it.*

```py
button = page.locator('//header[@class="_inline-sidesheet-header_1cn7lg"]//button[2]')
if button.is_disabled():
    break
if button.is_enabled():
    break
if button.is_hidden():
    break
if button.is_visible():
    break
if button.is_checked():
    break
if button.is_editable():
    break
```

> **Note:** `break` only works inside a `for` or `while` loop. Put these checks inside a loop, or replace `break` with your own action.

### 7.2 Advanced input in React-based applications

#### 01. Fill normal text

```py
# 01. Fill Normal Text
page.evaluate(
    """
    ({ elementSelector, value }) => {
        const element = document.querySelector(elementSelector);
        if (element) {
            element.focus();
            element.innerText = value;
            const inputEvent = new Event('input', { bubbles: true });
            element.dispatchEvent(inputEvent);
            const changeEvent = new Event('change', { bubbles: true });
            element.dispatchEvent(changeEvent);
            element.blur();
        }
    }
    """,
    {"elementSelector": "p[data-testid='editorParagraphText']", "value": content}
)  # p[data-testid='editorParagraphText'], change this querySelector locator

page.evaluate(
    """(companyName) => {
        const searchBox = document.getElementById("searchboxinput");
        searchBox.value = companyName;
        searchBox.dispatchEvent(new Event('input', { bubbles: true }));
    }""",
    "Search param"
)
page.evaluate("""document.getElementById('searchbox-searchbutton').click()""")
```

#### 02. Fill username

```py
# 02. Fill Username
    """
    ({ elementSelector, value }) => {
         const element = document.querySelector(elementSelector);
         if (element) {
            const nativeValueSetter = Object.getOwnPropertyDescriptor(element.__proto__, 'value').set;
            element.focus();
            nativeValueSetter.call(element, value);
            const inputEvent = new Event('input', { bubbles: true });
            element.dispatchEvent(inputEvent);
            const changeEvent = new Event('change', { bubbles: true });
            element.dispatchEvent(changeEvent);
            element.blur();
          }
    }
    """,
    {"elementSelector": "#username", "value": "admin"}
)
```

#### 03. Fill password

## Step 8. Click and mouse actions

*Use when: you need to click, double-click, right-click or hover.*

### 8.1 Click

```
https://playwright.dev/python/docs/input
```

#### Basic click, double-click, hover and keys

```py
element = page.locator('path').first
element.click()  / page.locator('path').first.click()
element.dblclick()
element.hover()
page.locator('path').first.type('text').press('Enter')
page.keyboard.press('Enter')
page.keyboard.send_character("A")                       # sending the character 'A' as if it were typed on the keyboard.
```

#### Click variants by role or text

```py
page.get_by_role("button").click()    # Generic click
page.get_by_text("Item").dblclick()   # Double click
page.get_by_text("Item").click(button="right")  # Right click
page.get_by_text("Item").click(modifiers=["Shift"])   # Shift + click
page.get_by_text("Item").hover()    # Hover over element
page.get_by_text("Item").click(position={ "x": 0, "y": 0})   # Click the top left corner
```

#### Advanced click (human-like)

```py
# Advance click
phone_ele = scraper_page.locator("div[data-tooltip-place='bottom'] button[title='voir le numéro']").first
if phone_ele.count() > 0:
    # Human-like interaction
    box = phone_ele.bounding_box()
    if box:
        x = box["x"] + box["width"] / 2 + random.uniform(-5, 5)
        y = box["y"] + box["height"] / 2 + random.uniform(-5, 5)
        scraper_page.mouse.move(x, y, steps=random.randint(8, 15))
        time.sleep(random.uniform(0.2, 0.5))
        phone_ele.click(delay=random.randint(100, 200))
```

> **Note:** `.type('text')` returns nothing, so chaining `.press('Enter')` after it will fail. Use `.type('text')` then `page.keyboard.press('Enter')`, or call `.press('Enter')` on the locator.

## Step 10. Wait

*Use when: the page is slow or content loads late.*

```
https://playwright.dev/python/docs/actionability
```

```py
page.goto('link', timeout=60000)                               # 1 min
page.wait_for_timeout(5000)                                    # Waits for the specified amount of time.
page.wait_for_load_state("load")                               # Wait for all elements
page.wait_for_selector('path')                                 # Wait for specific element
page.wait_for_selector_all('.item')                            # Waits for all elements matching
page.wait_for_function('document.readyState === "complete"')   # Waits for the specified function to evaluate to true
page.wait_for_url('https://www.linkedin.com/sales/*')          # Use a pattern to match LinkedIn's final page URL
phone_elem = page.locator("//a[@title='appeler']").first
phone_elem.wait_for(state="visible", timeout=15000)
```

> **Note:** `wait_for_selector_all` is not a Playwright method. Use `page.wait_for_selector('.item')` or `page.locator('.item').first.wait_for()`.

## Step 15. File upload with Playwright

*Use when: you need to upload a file through a file chooser.*

```py
import os
file_path = os.path.join(os.getcwd(), 'file.extension')
with page.expect_file_chooser() as fc_info:

sleep(1)
page.click("submit_button")  # submit button after upload image
```
